# Cloud Foundry (cloud-foundry)

Cloud Foundry is an open-source, multi-cloud Platform as a Service (PaaS) governed by the Cloud Foundry Foundation. The Cloud Controller API v3 is the primary control plane; UAA handles identity, Loggregator streams logs and metrics, and the Open Service Broker API powers the marketplace.
