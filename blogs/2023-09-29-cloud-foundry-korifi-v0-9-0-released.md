Release of the v0.9.0 of Korifi announced with support for pushing Docker images and other minor improvements. The Cloud Foundry Community announced the release of v0.9.0 of the Korifi project. This release includes support for pushing existing Docker images and also contains other minor improvements to the Helm charts used.
